#Monitoring
This directory contains SQL scripts used to monitor the status and basic performance od a MySQL server.


##Files

###mysq_status.sql
Contains SQL queries for checking the current state of the MySQL server, including:
-MySQL version
-Currents database
-Server uptime
-Active connections
-Running threads
-Executed queries
-Active sessions

###performance_check.sql
Contains SQL queries for basic performance monitoring, including:
-Slow queries
-InnoDB buffer pool statistics
-Temporary table statistics
-Table cache statistics


##Purpose
These scripts are uncluded for learning and practicing basic MySQL monitoring tasks in a Linux environment.
